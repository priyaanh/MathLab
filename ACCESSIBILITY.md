# Calculator Accessibility Guide

This scientific calculator has been designed with comprehensive accessibility features to ensure it's usable by everyone, including users with disabilities.

## 🎯 Accessibility Features Overview

### Keyboard Navigation
- **Full keyboard support** - No mouse required
- **Tab navigation** - Navigate through all buttons using Tab/Shift+Tab
- **Arrow key navigation** - Move within the button grid using arrow keys
- **Direct input** - Type numbers and operators directly
- **Focus indicators** - Clear visual feedback for keyboard focus

### Screen Reader Support
- **ARIA labels** - Descriptive labels for all buttons and controls
- **Live regions** - Automatic announcements of display changes
- **Role attributes** - Proper semantic structure for assistive technology
- **Grid navigation** - Buttons organized as an accessible grid

### Visual Accessibility
- **High contrast themes** - Three theme options for different needs
- **Focus outlines** - Bold, high-contrast focus indicators
- **Status banners** - Visual feedback for keyboard navigation state
- **Clear typography** - Readable fonts and appropriate sizing

## ⌨️ Keyboard Navigation Guide

### Starting Keyboard Navigation
1. Press **Tab** to enter keyboard navigation mode
2. A blue accessibility banner will appear briefly
3. An orange navigation banner shows available shortcuts

### Navigation Controls
- **Tab** / **Shift+Tab**: Move forward/backward through buttons
- **Arrow Keys**: Navigate within the button grid (when Tab navigation is active)
- **Enter** / **Space**: Activate the focused button
- **Escape**: Exit keyboard navigation mode

### Direct Input (Works anytime)
- **0-9**: Input numbers
- **+, -, *, /**: Mathematical operators
- **=** or **Enter**: Calculate result
- **.**: Decimal point
- **%**: Modulo operation
- **C**: Clear calculator
- **Backspace**: Delete last character

### Expression Editing
1. Click on the expression area (top display)
2. Use arrow keys to move cursor
3. Type directly to insert at cursor position
4. **Home**/**End**: Move to beginning/end
5. **Backspace**/**Delete**: Remove characters
6. **Escape**: Exit editing mode

- **Scientific functions** available in scientific mode

## 🔧 Troubleshooting

### Focus Not Visible?
- Try pressing Tab to activate keyboard navigation
- Check if high contrast mode is enabled in your OS
- Switch to Black/White theme for maximum contrast

### Screen Reader Not Announcing?
- Ensure screen reader is running
- Try refreshing the page
- Check if JavaScript is enabled

### Keyboard Not Working?
- Click on the calculator to focus it
- Ensure you're not in expression editing mode (press Escape)
- Try refreshing the page
